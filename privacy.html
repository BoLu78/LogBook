Logbook · Privacy and terms

Logbook is a personal pilot logbook used only by its author, Luca Bortolot.

Data. Logbook entries are stored on the user's own devices and, if the user connects Google Drive, in a single file (Logbook/logbook.json) and EASA PDF copies in the user's own Google Drive. The app uses the drive.file permission, so it can only see files it created itself.

No sharing. No data is sent to the author or to third parties, no analytics and no advertising are used. Weather and map data are downloaded from public services without any personal information.

Sign-in. A small Cloudflare Worker exchanges the Google sign-in for an access token so the app can stay connected. It does not store any data.

Terms. The app is provided as is, for personal use. It is not an official source of operational data.

Contact: via the Google account that owns this app.
