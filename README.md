# Logbook

PWA personale per il logbook pilota: elenco voli, inserimento, riepilogo totali e limiti, stampa in formato EASA (AMC1 FCL.050).

- Funziona offline e si installa da Chrome (menu ⋮ › Trasmetti, salva e condividi › Installa pagina come app).
- I dati restano nel browser e in una cartella di backup scelta dall'utente (`logbook.json` + copia giornaliera in `storico/`).
- Nessun dato di volo è contenuto in questo repository.
